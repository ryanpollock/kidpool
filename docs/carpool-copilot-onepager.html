The agent is used, not demoed

Crewmate AI (the in-chat copilot) lives in the parents' own group chat. It answers schedule questions and proposes changes as consent cards:

cancel a rideswap drivesplace a kidcover a gapadd an extra drive

20 cards proposed → 11 executed by parents in 8 weeks. Every execution runs through the same invariant-enforcing path as the app, notifies every affected family, and is audited.

Nothing changes without a parent's OK — the trust boundary is enforced in the executor, not the prompt.
